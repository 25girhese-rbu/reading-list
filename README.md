# Reading List Application

**Name:** Soniya Eknath Girhe. 
*Section_Roll_No.:* A7_B4_59.

A simple Laravel web application to track books you plan to read, are currently reading, or have finished.

## Features
- View reading list with filter tabs (All, To Read, Reading, Finished)
- Add new books with custom status
- Update book status directly from the list
- Delete books with confirmation prompt

## Tech Stack
- **Framework:** Laravel 11.x / 13.x
- **Database:** SQLite
- **Styling:** Tailwind CSS
